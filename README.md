# Wellspring corpus

The texts behind [Wellspring](https://wellspring-theta.vercel.app): public-domain and openly licensed editions, each with its provenance, rights and known limits in `content/<package>/source.json`. The register is `CORPUS.md`; font and library notices are in `THIRD-PARTY-NOTICES.md`. Served by GitHub Pages as static JSON; the app reads it from `CONTENT_BASE`.

Published 2026-09-23 from the Wellspring repository by `scripts/publish-corpus.mjs`.
