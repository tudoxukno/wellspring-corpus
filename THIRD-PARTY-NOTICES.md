## Wellspring identity and illustration

The user supplied a brand board and interface mockups. An AI-assisted transparent logo interpretation and standalone root/spring illustration were generated from those references using the built-in image generation tool on September 16, 2026.

The logo has genuine alpha transparency. Root details may differ from the supplied mark. The downloadable SVG variants embed this raster PNG and contain live wordmark text; they are not a fully vectorized production master. Validate the final identity before trademark or print use.

The illustration is a standalone asset; the app does not display a screenshot crop. No UI text or chrome is embedded in it.
